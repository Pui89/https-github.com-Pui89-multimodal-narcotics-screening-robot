# Robot simulation

Use Isaac Sim/Isaac Lab or Gazebo/ROS2 to validate:

- RGB-D and LiDAR perception
- SLAM and Nav2 navigation
- dynamic obstacle avoidance
- human exclusion zones
- sensor dropout
- emergency stop
- low-light/thermal disagreement
- unknown-object screening
- telemetry loss

Simulation should never be treated as proof of real-world narcotics identification accuracy.
