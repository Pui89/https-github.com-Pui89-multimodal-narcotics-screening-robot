# Evaluation

This directory defines a reproducible evaluation layer for the screening platform.

Recommended metrics: precision, recall, F1, AUROC where appropriate, expected calibration error, unknown/abstention rate, false-positive and false-negative rates, cross-modal agreement, degraded-sensor performance, end-to-end latency, and safety-gate violations.

Do not publish invented benchmark values. Populate reports only from reproducible runs with documented datasets, model versions, hardware and configuration.
