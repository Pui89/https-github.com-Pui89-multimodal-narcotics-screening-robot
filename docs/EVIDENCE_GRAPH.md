# Evidence Graph

The evidence graph links sensor observations, model outputs, spatial evidence, uncertainty, reviewer actions, and provenance for each screening event.

Core entities:
- screening event
- sensor observation
- perception result
- 3D evidence
- screening hypothesis
- uncertainty/OOD assessment
- human-review action
- provenance and model version

The graph digest is an integrity aid for audit records. It is not a legal chain-of-custody system by itself.
