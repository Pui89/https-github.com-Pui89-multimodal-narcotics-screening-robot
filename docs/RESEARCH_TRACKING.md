# Research and engineering tracking

Record Git SHA, dataset/model/config versions, sensor calibration ID, hardware, seed, metrics, calibration error, OOD metrics, abstention/review rates, robustness results, latency and resource usage.

Recommended state: NOT_RUN → RUNNING → REVIEW_REQUIRED → REPRODUCED → RELEASE_CANDIDATE → APPROVED.

A high-confidence model output is not by itself a validated capability.
