# Dataset and evaluation

Use lawful, consented or otherwise authorized data. Include benign lookalikes, empty scenes, occlusion, glare, low light, varied viewpoints, sensor dropout and environmental variation.

Track sensor type, calibration, capture session and annotation provenance. Keep scene/session-level train-validation-test separation.

Evaluate known-class precision/recall, open-set false-positive rate, false-negative rate, calibration error, occlusion robustness, sensor-dropout robustness, 3D localization error and reviewer override rate.
